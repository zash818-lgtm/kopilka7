# Бот трат с голосовыми + календарь (Telegram Mini App)

## 1. Получить ключи (5 минут)
1. **Бот:** @BotFather → `/newbot` → скопируй токен.
2. **Groq:** console.groq.com → войти → API Keys → Create → скопируй `gsk_...`.

## 2. Залить на GitHub
Создай приватный репозиторий и загрузи туда все файлы из архива (без `.env`).

## 3. Railway
1. railway.app → New Project → Deploy from GitHub → выбери репозиторий.
2. **Variables** → добавь:
   - `BOT_TOKEN` = токен от BotFather
   - `GROQ_API_KEY` = ключ Groq
   - `DB_PATH` = `/data/expenses.db`
3. **Settings → Volumes** → Add Volume → Mount path: `/data`. Без этого траты пропадут при каждом обновлении.
4. **Settings → Networking** → Generate Domain. Ссылка календаря подставится сама.
5. Нажми Redeploy.

## 4. Проверить
Напиши боту `/start` → запиши голосовое «вода 7 тысяч» → нажми кнопку «Календарь» слева от поля ввода.

## Как пользоваться
- 🎙 «стрижка 200 тысяч» — запишет трату
- 🧾 «такси 25 тысяч и кофе 30 тысяч» — две траты сразу
- ⏪ «вчера бензин 150 тысяч» — на вчерашний день
- ✏️ / 🗑 — кнопки под ответом бота
- `/today`, `/month`, `/undo`
- В календаре: тап по дню — список, тап по трате — изменить или удалить, «+» — добавить вручную

## Настройки (необязательно)
- `ALLOWED_USERS=123456789` — бот только для тебя (ID можно узнать у @userinfobot)
- `STT_LANGUAGE=` (пусто) — если говоришь по-узбекски, язык определится сам
- `TZ_NAME=Asia/Tashkent` — часовой пояс
